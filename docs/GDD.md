# Game Design Document — 클래식 테트리스

## 1. 게임 개요
| 항목 | 내용 |
|------|------|
| 장르 | 퍼즐 |
| 플랫폼 | Android |
| 타겟 연령 | 전연령 (어린이 포함) |
| 플레이 방식 | 세로 화면 (Portrait) |
| 세션 길이 | 1~10분 (캐주얼) |

## 2. 핵심 게임플레이

### 2-1. 기본 규칙 (클래식 테트리스)
- 7종류의 테트로미노(블록)가 위에서 아래로 떨어짐
- 플레이어는 블록을 좌/우 이동 및 회전시켜 쌓음
- 가로 한 줄이 빈칸 없이 채워지면 줄이 삭제되고 점수 획득
- 블록이 상단 경계를 넘으면 게임 오버

### 2-2. 테트로미노 종류
| 이름 | 모양 | 색상 |
|------|------|------|
| I-piece | ████ | 하늘색 (Cyan) |
| O-piece | ██<br>██ | 노란색 (Yellow) |
| T-piece | ███<br>·█· | 보라색 (Purple) |
| S-piece | ·██<br>██· | 초록색 (Green) |
| Z-piece | ██·<br>·██ | 빨간색 (Red) |
| J-piece | █··<br>███ | 파란색 (Blue) |
| L-piece | ··█<br>███ | 주황색 (Orange) |

### 2-3. 게임 보드
- 크기: 10열 × 20행 (표준 테트리스)
- 숨겨진 버퍼 존: 상단 2행 (블록 스폰 영역)

## 3. 조작 방법 (터치 기준)

| 동작 | 기능 |
|------|------|
| 좌/우 스와이프 | 블록 이동 |
| 탭 | 블록 회전 |
| 아래 스와이프 | 소프트 드롭 (빠르게 내리기) |
| 빠른 아래 스와이프 | 하드 드롭 (즉시 착지) |

## 4. 점수 시스템
| 이벤트 | 점수 |
|--------|------|
| 1줄 제거 | 100 × 레벨 |
| 2줄 동시 제거 | 300 × 레벨 |
| 3줄 동시 제거 | 500 × 레벨 |
| 4줄 동시 제거 (테트리스!) | 800 × 레벨 |

### 레벨 시스템
- 10줄 제거마다 레벨 +1
- 레벨이 오를수록 블록 낙하 속도 증가

## 5. UI 구성

### 메인 게임 화면
```
┌─────────────────┐
│  SCORE: 00000   │
│  LEVEL:  1      │
│  LINES:  0      │
├──────────┬──────┤
│          │ NEXT │
│  게임    │ ┌──┐ │
│  보드    │ │  │ │
│ (10×20)  │ └──┘ │
│          │      │
└──────────┴──────┘
```

### 화면 목록
1. **메인 메뉴** — 타이틀, 시작 버튼, 최고점수
2. **게임 화면** — 보드, 점수, 다음 블록 미리보기
3. **일시정지** — 재개, 재시작, 메뉴로 가기
4. **게임 오버** — 점수, 재시작, 메뉴로 가기

## 6. 오디오
| 항목 | 내용 |
|------|------|
| BGM | 밝고 캐주얼한 루프 음악 |
| 블록 이동 | 짧은 클릭음 |
| 블록 착지 | 둔탁한 착지음 |
| 줄 제거 | 경쾌한 효과음 |
| 테트리스 | 특별한 팡파레 |
| 게임 오버 | 짧은 실패음 |

## 7. 개발 단계 (Phase)
- **Phase 1**: 핵심 게임플레이 구현 (보드, 블록, 이동, 회전, 줄 제거)
- **Phase 2**: UI 구현 (점수, 레벨, 메뉴, 게임 오버)
- **Phase 3**: 오디오 추가
- **Phase 4**: 터치 입력 & 모바일 최적화
- **Phase 5**: 광고 연동 & Google Play 출시 준비
